\# ❤️ Heart Disease Prediction using Machine Learning



\## Overview



This project predicts the likelihood of heart disease using Machine Learning algorithms. It includes data preprocessing, exploratory data analysis, model training, evaluation, and a Streamlit web application for real-time predictions.



\---



\## Features



\* Data preprocessing and cleaning

\* Exploratory Data Analysis (EDA)

\* Multiple ML models:



&#x20; \* Logistic Regression

&#x20; \* Decision Tree

&#x20; \* Random Forest

\* Model performance comparison

\* Streamlit web application

\* Real-time heart disease prediction

\## Installation



Clone the repository:



```bash

git clone https://github.com/Supraja73/heart-disease-prediction.git

cd heart-disease-prediction

```



Install dependencies:



```bash

pip install -r requirements.txt

```



\---



\## Run the Application



\### Training Pipeline



```bash

python app.py

```



\### Streamlit Web App



```bash

streamlit run streamlit\_app.py

```
